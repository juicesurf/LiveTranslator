# LiveTranslator

macOS 即時英中雙語字幕工具。讀取系統 Live Captions 的英文字幕，用 Apple Translation 翻譯為繁體中文，顯示在可置頂的浮動視窗。

- 英文與中文逐句對照，長句隨視窗寬度換行。
- 等完整句尾（`. ? !`）後翻譯；處理字幕更新、修正與重疊。
- 可調字體、透明度、深淺色與僅中文顯示。
- 上捲查看歷史時暫停自動跟隨，捲回底部後恢復。
- 逐句經過時間，TXT／Markdown 匯出與未儲存提醒。
- Apple Intelligence 裝置端繁中重點整理，可回查英文來源、複製或匯出 Markdown。
- 不需 API Key、不使用付費翻譯 API、不上傳第三方服務。字幕預設只留在記憶體，主動儲存才寫入檔案。

## 環境需求

- macOS 26.0 以上，並且系統可使用英文 Live Captions。
- 完整 Xcode（只有 Command Line Tools 不足夠）。首次使用先開啟 Xcode，接受條款並完成元件安裝。
- 本專案目前驗證環境：Apple Silicon M2、macOS 26.5.2、Xcode 26.6、Swift 6.3.3、macOS 26.5 SDK。其他硬體／版本尚未完整驗證。
- 首次準備翻譯模型需要網路；模型及語言支援由系統確認，離線使用仍需在自己的 Mac 實測。

## 用 Terminal 下載、編譯及打包

在 Terminal 逐行執行：

```bash
git clone https://github.com/juicesurf/LiveTranslator.git
cd LiveTranslator
bash scripts/package.sh
```

若已用 GitHub「Code → Download ZIP」下載，解壓縮後，在 Terminal 輸入 `cd `（含空格），將解壓縮的專案資料夾拖入 Terminal，按 Enter，再執行：

```bash
bash scripts/package.sh
```

腳本會使用本機 Xcode 編譯 Release，進行 ad-hoc 簽署並產生：

| 成品 | 位置 |
| --- | --- |
| 可直接啟動的 App | `build/package/Build/Products/Release/LiveTranslator.app` |
| 壓縮包 | `dist/LiveTranslator.zip` |

不需要付費 Apple Developer 帳號、Developer ID、公證或 Xcode Archive 操作。這裡的 Release 是本機編譯設定，並不代表已完成正式發佈簽署。ZIP 會覆蓋先前同名的打包成品，不會包含原始碼或逐字稿。

在專案目錄啟動：

```bash
open build/package/Build/Products/Release/LiveTranslator.app
```

也可以在 Finder 雙擊 App；若要移到「應用程式」，請先結束 App，再移動並從新位置開啟，之後對同一位置的 App 授權。

> 這個流程主要供下載者在自己的 Mac 編譯使用。將此 ad-hoc ZIP 再傳給另一台 Mac，仍可能受到系統安全檢查阻擋；它不是 Developer ID 簽署／公證的安裝包。

## 第一次使用

1. 開啟 macOS「系統設定 → 輔助使用 → 即時字幕／Live Captions」，設定英文，播放英文內容，確認系統字幕本身有文字。
2. 開啟 LiveTranslator，右上角「更多操作」（⋯）選「授予輔助使用權限」。
3. 到「系統設定 → 隱私權與安全性 → 輔助使用」，啟用 **LiveTranslator**。必要時按 +，加入剛編譯的 App。Terminal 的權限不會代替 App 的權限。
4. 在「更多操作」按「準備模型／重試翻譯」，接受 Apple 的模型下載提示。
5. 按「開始擷取」（尚未初始化翻譯時會自動準備模型）。英文句尾出現後才會翻譯；沒有句尾時顯示「等待完整句子」。

可先停止擷取，再從「更多操作」按「測試英翻繁中」，驗證固定測試句。關閉字幕視窗只停止擷取，不會結束 App；點 Dock 圖示或按 ⌘0 可重開。

## 儲存字幕

右上角「⋯ → 儲存逐字稿」可選 TXT 或 Markdown。匯出本次全部字幕，包含捲動上方內容，依「經過時間 → 英文 → 中文」排列。時間不是影片播放位置；同一句修正後會保留原時間，停止／重開擷取不歸零，清除後重新計時。

有尚未匯出的字幕、修正或翻譯時，清除或 ⌘Q 會提醒儲存。提醒與後續儲存期間暫停更新；取消或失敗時保留字幕並恢復更新。一般手動匯出不停止擷取，晚於匯出快照的新內容仍視為未儲存。

## 更新程式

先儲存需要的字幕，⌘Q 結束 App，再於原始碼目錄執行：

```bash
git pull --ff-only
bash scripts/package.sh
open build/package/Build/Products/Release/LiveTranslator.app
```

## 常見問題

**`xcodebuild` 找不到完整 Xcode，或顯示 Command Line Tools 錯誤**

先安裝完整 Xcode。若 Xcode 安裝在標準位置，可在確認路徑後執行以下指令；系統會要求管理員密碼：

```bash
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
```

再開啟 Xcode，完成首次設定，重跑打包腳本。若 Xcode 安裝在其他位置，請使用實際路徑。

**重新編譯後顯示需要輔助使用權限**

本機 ad-hoc 簽署可能使舊權限紀錄失效。⌘Q 結束 App，在輔助使用權限清單用 − 移除舊 LiveTranslator，再用 + 加入新的 App，啟用後重新開啟。單純切換開關可能不足。

**一直沒有中文**

先確認模型已準備、系統支援 en → zh-Hant，再確認英文有句尾。若持續沒有標點，程式會等待完整句子，不會用時間或字數強制拆開。「更多操作 → 顯示診斷」可查看狀態與耗時。

**已知限制**

Live Captions 的 Accessibility 階層是系統實作細節，系統更新可能影響讀取。縮寫句尾採保守判斷；完全相同 snapshot 無法區分真正重複說話與畫面未變；沒有重疊的大幅辨識修正仍可能產生額外段落。多螢幕、全螢幕、離線翻譯與模型品質需在各自環境驗證。

## 開發與測試

也可用 Xcode 開啟 `LiveTranslator.xcodeproj`，選 LiveTranslator／My Mac，按 Run。

```bash
swift test --scratch-path build/swift-tests
```

## 雙語筆記模式

按工具列「筆記」或 ⌘⇧N 在雙語字幕／雙語筆記間切換；也可從顯示設定或「檔案」選單切換。筆記模式使用米白背景、英中皆為 14pt、相同一般字重與文字顏色、英中段落對照，只呈現已完成翻譯的句子。隱藏時間、翻譯等待狀態與底部診斷，滑鼠移到內容頂部才顯示控制列；操作列保留固定空間，避免滑鼠移入移出造成內容跳動。

筆記視窗標題為「筆記」，預設不置頂且不跨所有桌面顯示，仍可用圖釘置頂。切回字幕模式會恢復原本的字體、深淺色、透明度、僅中文及置頂偏好。模式不改變擷取、翻譯、儲存內容或清除記錄，沒有額外啟用語音／外部服務，也不會將逐句翻譯改成摘要。模式選擇目前只在本次執行期間保留。

此更新已通過 Release 打包與 33 個測試；實際懸停控制列、縮放、切換時保留捲動位置及其他 App 輸入焦點，仍需在使用者環境確認。

字幕與筆記模式的「儲存 TXT／儲存 Markdown」均位於右上角 ⋯ 選單；筆記模式請先將滑鼠移至頂部顯示控制列。

## 整理本次重點（第一版）

在字幕／筆記模式的「⋯」選單選擇「整理本次重點」。需要 Apple Intelligence 已啟用、裝置端模型已就緒且支援繁體中文；無法使用時會顯示原因，不會改用第三方服務。這與 Apple Translation 的語言模型分開，不代表能翻譯就一定能摘要。

- 只處理按下按鈕時已完成的原始英文句子，不使用逐句中文譯文，也不錄音。不完整尾句會略過，結果列出略過數量。
- 獨立結果視窗提供簡短摘要、主要重點與明確待辦。每項附來源時間與可展開的英文，時間是擷取經過時間，不是影片播放位置。
- 長篇先依句子分段，過長的單一句會保留來源編號再拆成片段；各段整理後以兩兩合併縮成最終摘要。每次使用新模型 session 避免對話歷史累積。超過模型容量或輸出限制時顯示錯誤，不靜默省略整段輸入。
- 來源編號會檢查是否屬於輸入；待辦還必須附可核對的原文工作承諾。第一版使用保守英文規則（如 will、must、agreed to），可能漏掉其他說法，不能保證所有待辦或所有語意均正確。未知資訊不應推成新的工作。
- 擷取與翻譯仍繼續，結果只對應已凍結的快照；按結果視窗「重新整理」才納入最新內容。已有結果時從選單重開會顯示原結果，不會直接覆蓋。
- 可取消整理，關閉結果視窗也會取消未完成工作；取消後不回填遲到結果。只在使用者明確開啟結果時切換視窗，背景進度不主動啟用 App。結果視窗位於浮動字幕前方，切換到其他 App 時會隱藏，可從「⋯」重開。
- 「複製」複製 Markdown（含摘要與英文來源），可貼到備忘錄；「匯出 Markdown」由使用者選擇位置寫檔。不會自動建立備忘錄或永久保存摘要；需要保留時請先複製／匯出。此功能尚未加入摘要專屬的退出儲存提醒。

驗證：40 個不呼叫模型的測試通過；另以固定範例執行 2 個 Apple 裝置端模型測試，涵蓋人名、待辦證據、排除未定預算衍生任務，以及分段合併／無待辦內容。一般測試預設略過這 2 個模型測試，開發者可明確啟用：

```bash
LIVE_TRANSLATOR_MODEL_SMOKE=1 swift test --scratch-path build/model-smoke --filter actualAppleModel
```

上述模型實測使用固定文字，不讀取使用者字幕。Release 編譯與打包已通過；實際結果視窗、取消、複製、儲存面板及真實講座摘要品質仍需手動驗證。AI 摘要可能遺漏或誤解內容，來源引用只提供回查依據，不等於已驗證每一項敘述。

## 逐字稿真實時間

字幕模式及 TXT／Markdown 匯出會依序顯示「擷取經過時間、首次擷取的當地真實時間」，例如 `[00:02:15] [14:32:08]`。同一句被修正或翻譯完成仍保留原始 timestamp。筆記模式繼續隱藏時間。

匯出標示擷取日期與時區；同一份記錄跨日時，每句真實時間會加上日期，遇到夏令時間切換導致 UTC offset 改變時亦標上各句 offset。此時間是 App 首次讀到該句的時間，不代表精確發話時刻或影片時間。摘要引用仍採擷取經過時間。

此調整的 41 個一般測試通過（另 2 個需明確啟用的模型測試本次略過），包括 Auckland 時區跨午夜與兩種匯出格式；Release 打包成功。

## 即時字幕落後的排程改善

擷取期間優先翻譯最新的完整英文句子，避免新句一直排在歷史待譯內容後面。歷史英文與已完成翻譯仍保留；停止擷取後按時間順序補齊待譯內容。已送出的單次翻譯仍需等待模型返回，不保證無延遲。

字幕模式底部會顯示英文來源最後變動的當地時間與待譯句數，翻譯中會標出正在處理的句子首次擷取時間。若系統字幕在變但來源最後更新時間不變，應檢查 Accessibility 來源；若來源更新而待譯增加，則是翻譯排程／模型速度。筆記模式只呈現英中均完成的句子，診斷時請先切到字幕模式並捲至底部。

此版本 43 個一般測試通過（另 2 個模型測試本次略過），包含即時優先最新、歷史保留與來源變動時間。Release 打包成功；真實講座延遲仍須使用者確認，不能由單元測試判定讀取來源一定正確。

## 來源停在舊句與翻譯未啟動的修正

讀取字幕區時不再遇到第一個 AXStaticText 就停止，而是按 AX 階層順序取最後一個有效字幕文字節點，避免多個文字節點時持續讀取較舊內容；不串接多個節點，並略過精確匹配的系統暫停標籤。診斷會列出節點數與最後幾個候選屬性。AX 順序仍屬系統實作細節，是否與實際最新文字一致需在本機核對。

每次啟動 App 後，按「開始擷取」會在尚無翻譯 configuration 時自動準備翻譯，不再要求使用者每次另按準備模型；既有 session 不會因此重建。首次下載仍可能要求使用者確認。這兩處是與排程積壓不同的問題，不能僅由一張截圖斷定唯一原因。

此版本 45 個一般測試通過（另 2 個裝置端模型測試略過），涵蓋讀取最新候選與初始化不重複重設。Release 打包成功。若系統字幕持續改變但 App「英文來源最後更新」不動，仍需提供完整底部狀態／AX 診斷以進一步核對。

## 摘要長度的容錯處理

160 字摘要／90 字重點等長度是閱讀目標，不再當作整份結果的失敗條件。超出目標時，會用相同引用資料自動要求一次更精簡版本；若重試失敗或沒有更短，保留來源編號有效的原結果。最終仍偏長時會在畫面及 Markdown 標示，不直接截斷句子或丟棄整份摘要。無效來源編號、空結果與取消操作仍會正確處理。

此修正 47 個一般測試通過（一般測試另略過 2 個模型實測），另單獨執行 2 個裝置端模型實測亦通過。測試涵蓋超限重試使用相同來源、重試失敗保留完整結果與警告，以及既有長文合併和待辦證據檢查。Release 已重新打包。
